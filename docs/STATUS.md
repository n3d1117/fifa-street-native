Unverified: physical controller input, audible audio, saves, quiet device cadence, sustained thermals and tvOS hardware. Device observations regenerate with `./rx device install --lean`, `./rx device push-data` and `./rx device run --seconds 150`.

2. Measure quiet NTSC game/present cadence and thermals without DVT or perf logging; confirm the PAL opt-in still paces at 50 Hz on device.
3. Pipeline prewarm: feature-only manifest sections cover the M1 NTSC/PAL selectors and simulator capability profile. The iPhone 11 A13 matches `shader=3;fbf=1;primid=1;rov=1;rrt=0;rr32=0;depth=0;broken=1`. Its 258-key section covers the 151 distinct selectors recorded on match routes at venues 3 and 5, the seven previously absent keys, and one more key surfaced by a clean venue-3 baseline. `./rx device baseline --runs 2 --seconds 150 --label pipeline-keys-7` measured zero gameplay and total runtime pipeline compiles; both startup prewarms compiled 258 keys. `./rx device ab` regenerates comparisons. On macOS, both prewarm-on and prewarm-off `./rx run --match --seconds 60` runs measured 60.0 FPS and zero underruns. Other GPU feature profiles and fresh OS shader caches remain unverified. Metallib and `MTLBinaryArchive` work stays deferred until measured library or post-update stalls justify it.
4. Apple GPU paths from ARMSX2 (each needs a switch and A/B): framebuffer-fetch ordering instead of barriers, iOS barrier rules. The Z-floor skip is moot (no depth quantisation in the pinned GS) and the other fixes are already upstream.
5. Parked: small settings overlay (video mode, scale, rumble) usable with a controller and TV-safe on tvOS; real app icon for macOS, iOS and tvOS (macOS uses the generated placeholder from `tools/package/make-icon.m`; tvOS needs layered images).

6. iOS/tvOS termination crash (pre-existing): when UIKit terminates the app (`simctl terminate`, Xcode Stop), `exit()` runs static destructors and `GSTextureCache::~GSTextureCache` -> `RemoveAll` -> `Target::~Target` faults on the main thread (EXC_BAD_ACCESS, GSTextureCache.cpp:8098) while the GS renderer is still live. Only at termination; fix by shutting the GS bridge down before exit or skipping static teardown.
